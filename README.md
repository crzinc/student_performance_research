# Student Performance Prediction: Exploratory Data Analysis & Machine Learning

## 📌 Описание проекта
Данный проект посвящен прогнозированию итоговой успеваемости студентов (`G3`) на основе социально-демографических и поведенческих признаков. Основная ценность работы заключается в глубоком исследовании аномалий данных (нулевых оценок) и выявлении скрытых зависимостей между образом жизни студента и его успехами.

## 🔍 Основные этапы исследования

### 1. Расследование аномалии "Нулевого балла"
Был обнаружен статистический всплеск нулевых оценок в целевой переменной `G3`. 
- **Инсайт:** У студентов с `G3 = 0` зафиксировано **0 пропусков** (`absences`). 
- **Вывод:** Это административные нули (dropout/недопуск), а не результат академической оценки знаний. В модели регрессии такие значения классифицируются как шум.

### 2. Факторы влияния
- **Алкоголь:** Потребление алкоголя в будни (`Dalc`) является катализатором пропусков занятий, что опосредованно обнуляет результат.
- **Поддержка:** Школьная поддержка (`schoolsup`) чаще коррелирует с низким баллом, так как выделяется уже отстающим студентам.
- **Инфраструктура:** Наличие интернета и время на учебу (`studytime`) — ключевые позитивные предикторы.
