# Student Performance Analysis: Investigating the "Zero-Grade" Anomaly

Этот проект посвящен анализу успеваемости студентов и разработке модели машинного обучения для прогнозирования итоговой оценки (`G3`). Основной акцент сделан на выявлении скрытых закономерностей в данных и очистке датасета от технических аномалий.

## 📌 Описание проекта
Данное исследование базируется на наборе данных **UCI Student Performance Data Set**. Цель — понять, какие социальные, поведенческие и академические факторы сильнее всего влияют на успех студента, и решить проблему аномального распределения оценок.

## 🔍 Ключевые находки (EDA)

### 1. Загадка «Нулевых оценок»
В ходе анализа распределения `G3` был обнаружен значительный пик в районе 0 баллов. 
*   **Инсайт:** Студенты с `G3 = 0` имеют **0 пропусков** (`absences`). 
*   **Вывод:** Это «технические нули» (dropout/неявка на экзамен), а не реальный показатель знаний. Для построения точной регрессионной модели эти данные классифицируются как шум и подлежат фильтрации.

### 2. Цепочка деструктивного влияния (Алкоголь и Прогулы)
*   Потребление алкоголя в будни (**Dalc**) коррелирует с ростом пропусков.
*   **Парадокс здоровья:** Студенты, злоупотребляющие алкоголем, склонны переоценивать свое здоровье в опросах, что делает признак `health` малоинформативным для ML-модели.

### 3. Предикторы успеха
*   **G2 (Предыдущая оценка):** Сильнейший фактор. Результаты второго триместра почти линейно определяют финал.
*   **Study Time:** Существует четкая медианная разница между успешными и неуспешными студентами.
*   **Internet:** Наличие доступа к сети является значимым социальным предиктором успеха.
*   **School Support:** Удивительно, но школьная поддержка чаще оказывается студентам в зоне риска, что создает отрицательную корреляцию с итоговой оценкой.

## 🛠 Методология и Feature Engineering

Для улучшения качества предсказаний в проекте реализованы следующие шаги:
1.  **Фильтрация данных:** Удаление записей с `G3=0` для регрессионных моделей.
2.  **Группировка алкоголя:** Объединение признаков `Dalc` и `Walc` в общий индекс алкоголизации.
3.  **Создание признаков:**
    *   `social_risk`: Комбинация уровня алкоголя и количества прогулов.
    *   `academic_consistency`: Разница между оценками G1 и G2.
4.  **Обработка категориальных признаков:** One-Hot Encoding для типа школы, места жительства и работы родителей.
